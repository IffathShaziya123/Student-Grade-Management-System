
# Student Grade Management System

## About the Project
This is a beginner-friendly Python project that collects student information and calculates academic performance.

## Features
- Collects student name
- Collects college name and department
- Accepts marks for five subjects
- Calculates total marks
- Calculates average marks
- Displays highest and lowest marks

## Technologies Used
- Python

## Concepts Used
- Variables
- Data Types
- Input and Output
- Lists
- Arithmetic Operators
- Built-in Functions (sum, max, min, len)

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python student_grade.py
```
